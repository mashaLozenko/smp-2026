# Висновок

Для свого застосунку Language Buddy я б обрала формат JSON, оскільки він має зрозумілу структуру та є зручним для роботи з налаштуваннями. На мою думку, його головною перевагою є чітке представлення даних, що дозволяє легко розрізняти списки, вкладені об'єкти та різні типи значень. Хоча JSON не підтримує коментарі, його синтаксис здався мені простішим і зрозумілішим порівняно з YAML і TOML. Під час практичної роботи я також помітила, що в YAML деякі значення можуть автоматично змінювати свій тип, тому потрібно уважно використовувати лапки. З TOML  в мене з самого початку були проблеми, тому саме цю мову вважаю незручною для себе. Гадаю, що JSON буде хорошим вибором для цього застосунку, адже розробникам буде зручно переглядати та змінювати його налаштування.
