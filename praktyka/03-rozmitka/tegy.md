# Чому саме ці теги

| Тег | Що означає | Чому тут він, а не div |
|---|---|---|
| `nav` | Блок із навігаційними посиланнями по сторінці. | Я використала `nav`, тому що всередині знаходяться посилання на розділи «Про мене», «Навчання» та «Плани». `div` не пояснював би, що це саме навігація. |
| `main` | Основний вміст сторінки. | У `main` знаходиться головна інформація про мене. Цей тег одразу показує браузеру та читалці, де основний вміст сторінки, а `div` такого значення не має. |
| `section` | Окремий тематичний розділ сторінки. | Я використала `section`, щоб розділити інформацію на «Про мене», «Навчання» та «Плани». `div` просто створив би блок, але не показав би його змістовне призначення. |
| `figure` | Окремий блок для зображення або іншого матеріалу, пов'язаного з текстом. | Я використала `figure` для скріншота тренажера Git разом із його підписом. Так зрозуміло, що картинка та підпис пов'язані між собою. |
| `footer` | Нижня частина сторінки з додатковою інформацією. | У моєму `footer` знаходиться дата оновлення сторінки. `footer` показує, що це завершальна частина сторінки, а `div` був би просто блоком без конкретного значення. |
